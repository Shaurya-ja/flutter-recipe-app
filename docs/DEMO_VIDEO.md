# Demo-video capture checklist

Record a 30–60 second video using an Android emulator or device. Show these states in order:

1. Launch the app and wait for the **Meal Categories** grid.
2. Select a category such as **Chicken**.
3. Open one recipe from the list.
4. Scroll through the instructions and tap the favourite icon.
5. Show the confirmation message.

Before submission, upload the completed video to a GitHub release or approved video host and place the public link in the repository README.
